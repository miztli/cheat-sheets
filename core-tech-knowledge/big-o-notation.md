### O(1) - Constant Time
The time execution of the algorithm is constant and does not depend on input size

Eg:
- Array lookup
- Map insert/lookup key

### O(log N) - Logarithmic Time
The time execution of the algorithm grows logarithmically with the input size

Eg:
- Binary Search on BST

### O(N) - Linear Time
The time execution of the algorithm grows linearly with the input size.

Eg:
- Sum of array elements
- Array search
- Insert or remove from the middle

### O(N log N) - Loglinear Time
The time execution of the algorithm combines linear time and logarithmic time.

Eg:
- Merge sort
- Heap sort

### O(N^2) - Quadratic Time
The time execution of the algorithm grows quadratically with the input size.

Eg:
- Traverse a matrix with 2 nested loops

### O(N^3) - Cubic Time
The time execution of the algorithm grows cubically with the input size.

Eg:
- Traverse a matrix with 3 nested loops

### O(2^N) - Exponential Time
The time execution of the algorithm grows exponentially with the input size. 
Recursive algorithms.

Eg:
- Iterate over a JSON object recursively
