# Gemini useful commands

### Plan mode
Start directly in plan mode
`gemini --approval-mode=plan`

### Session

- Name: `/chat save P95-dxl-graphql-report-to-jira-csv`
- List: `/resume list`
- Open: `/resume resume P95-dxl-graphql-report-to-jira-csv`

### MCP

List available mcp servers
`/mcp list`

### Skills
Add specialized capabilities without cluttering the context immediate window
Generate a skill - To generate a skill just work in a prompt and fine-tune it until ready. Once the result is ready and verified, ask gemini to turn it into a skill and that's all.

List skills
`/skill list`
