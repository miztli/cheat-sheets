# Wiremock

### Run as standalone process
`java -jar wiremock-standalone-3.13.2.jar`

### FAQ
- How do you create an API mock? - WireMock supports several approaches for creating mock APIs - in code, via its REST API, as JSON files and by recording HTTP traffic proxied to another destination.
